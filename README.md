# Excel-Project-1
## Project Overview

Fundamental Booster is an Excel practice project designed to build
and demonstrate fundamental spreadsheet skills using student, sales, and
employee datasets. The project covers formulas, lookup functions, text
manipulation, date and time calculations, mathematical functions, and
dynamic references.

## Datasets

The project uses three datasets:

Student Data: Student ID, Name, Math, Science, English, and
Enrollment Date.

Sales Data: Sales ID, Product, Region, Salesperson, Amount, and
Date.

Employee Data: Employee ID, Name, Department, Salary, and
Joining Date.

## Project Objectives

Classify student grades using IF and nested IF formulas.

Count students who meet score criteria using COUNTIFS.

Retrieve student names and product prices using VLOOKUP.

Look up employee salaries dynamically using XLOOKUP.

Format and analyze employee joining dates.

Extract students with scores above 80 using FILTER.

Apply relative and absolute cell references and cell formatting.

Use IF with AND/OR to evaluate multiple conditions.

Calculate conditional totals and averages using SUMIFS and
AVERAGEIFS.

Perform dynamic lookups with INDEX and MATCH.

Manipulate text with LEFT, FIND, UPPER, and LOWER.

Find product positions using XMATCH.

Create dynamic references and ranges using INDIRECT and OFFSET.

Calculate date differences and practice ROUND, CEILING, and FLOOR.

Excel Skills Demonstrated

## Cell references: relative references such as A1 and absolute
references such as $A$1

Logical formulas: IF, nested IF, AND, and OR

Conditional calculations: COUNTIFS, SUMIFS, and AVERAGEIFS

Lookup and matching: VLOOKUP, XLOOKUP, XMATCH, INDEX, and
MATCH

Text functions: LEFT, FIND, UPPER, and LOWER

Dynamic references: INDIRECT and OFFSET

Date and time calculations

Math and rounding functions: ROUND, CEILING, and FLOOR

## Multiple-result extraction using FILTER

This project specification includes functions such as XLOOKUP,
XMATCH, and FILTER, which are not available in Excel 2007. For an
Excel 2007 environment, use compatible alternatives where appropriate,
such as VLOOKUP or INDEX/MATCH for lookups and an INDEX-based
array formula for extracting matching rows. The exact alternative
depends on the task and worksheet layout.

## How to Use

Open the workbook and identify the Student, Sales, and Employee
datasets.

Apply each required formula in the appropriate worksheet or output
columns.

Fill formulas down for all relevant data rows.

Format dates, currency, and headings consistently.

Check the outputs against the task conditions.

## Expected Learning Outcomes

By completing this project, the learner will practice essential Excel
skills, perform conditional analysis, retrieve data from tables, work
with dates and text, and build dynamic formulas.
